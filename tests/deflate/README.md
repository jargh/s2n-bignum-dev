# Tests of the DEFLATE specification

These files test `common/rfc1951.ml`, the HOL Light specification of DEFLATE
decoding (RFC 1951), against zlib.

* `rfc1951_ref.py` is a Python mirror of the specification. Each of its
  functions follows one of the definitions or inductive relations of the HOL
  file, rather than aiming for speed.
* `test_ref.py SEED N` compares the mirror with zlib's raw inflate: on
  streams that zlib produces from N inputs, at all levels and strategies,
  with flushes and trailing bytes, on mutations of them, and on random
  bytes. It checks acceptance, the output and the number of bytes used.
* `craft.py SEED N` does the same for N streams built directly from chosen
  code lengths, many of them invalid, to reach the corners of the format:
  incomplete, over-subscribed and single-code codes, bad repeat codes,
  missing end-of-block codes, distances too far back and so on. It reports
  which corners were reached.
* `rfc1951_checks.ml` checks in HOL that the fixed Huffman codes of the
  specification agree with the table in section 3.2.6 of the RFC and are
  complete.
* `rfc1951_eval.ml` defines `DEFLATE_DECODE_RULE`, which proves
  `deflate_decode l out n` for a concrete input `l` by following the
  relations of the specification step by step. `hol_tests.ml`, generated by
  `make_hol_tests.py`, uses it on small streams of every kind and checks the
  output and the number of bytes used against zlib.

From the repository root, run for example

    python3 -I tests/deflate/test_ref.py 1 300
    python3 -I tests/deflate/craft.py 1 3000

and in HOL Light, `loadt "tests/deflate/hol_tests.ml";;`, which should end
with `hol_tests_ok = true` (it takes a few minutes).
